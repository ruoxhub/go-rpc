# 07｜标准分析报告模板

复制下方模板建立一次正式评审记录。R 与 G 区块二选一；未发布视频不填真实数据区。模板补齐了正文明确要求但原模板漏列的比例、帧率、流量类型、平均观看时长和评论质量，不改变评分规则。

# 1\. 命名建议

`日期｜产品或 SKU｜R参考 / G生成｜短标题｜v版本`

示例：`2026-08-06｜男士运动短裤黑色｜G生成｜腰头拉伸｜v03`

# 3\. 提交前检查

* [ ] R/G 路线只选一个，C \+ 专项分总计 100

* [ ] G0 与所有扣分都能追溯到时间码

* [ ] 缺商品参考图时没有断言商品还原准确

* [ ] 真实数据没有混入 100 分

* [ ] BLOCK 没有被高总分覆盖

* [ ] 下一轮只有一个主要变量和一个可判定成功标准

* [ ] Owner 人工决定已记录
