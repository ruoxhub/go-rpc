# 03｜G0 硬门禁与决策规则

**命中任一硬失败即为 BLOCK。**可以继续计算诊断分，但不能判定为可发布成片；其他维度高分不得抵消。

# 1\. 商品类硬失败

- 商品颜色、长度、版型或关键结构漂移。

- Logo、图案、抽绳、口袋或拉链增减。

- 无后袋商品生成后袋。

- 正背面结构冲突。

- 内外两层衣物粘连或同步受力。

- 商品在关键展示段被完全遮挡。

- 将未知性能写成已证明事实。

# 2\. 人物与物理硬失败

- 人物换脸、换体型或纹身大幅漂移。

- 多肢、手指畸形或手穿过商品。

- 动作缺少释放或恢复。

- 人物、车辆、宠物发生穿模。

- 面料变成橡胶、薄膜、裙摆或异常撕裂。

# 3\. 镜头与交付硬失败

- 要求一镜到底却出现状态重置。

- 关键动作或关键镜头缺失。

- 视频时长不符合要求。

- 严重闪屏、黑帧、虚焦或过曝。

- 出现错误文字、水印或品牌标识。

- 不露脸要求被破坏。

# 4\. 统一评分锚点

|达成比例|判断标准|
|---|---|
|100%|有明确正面证据，稳定完成，无明显缺陷|
|80%|存在轻微问题，但不影响商品理解或主要卖点|
|60%|基本可用，但存在明显可见问题|
|40%|关键内容部分失败，需要定向重做|
|20%|严重失真，大部分不可用|
|0%|缺失、完全错误或灾难性失败|

满分必须有时间码正面证据。原稿没有明确“维度满分 × 达成比例”的计算、锚点之间是否允许自由给分、N/A 和取整规则；正式启用前见 [08｜治理待确认与版本记录](https://scn4i0kciem9.feishu.cn/docx/FFWud3euioSsL7xEwVLcWU6Dnff)。

# 5\. 等级与默认决策

|分数|等级|默认决策|
|---|---|---|
|85–100|S|高价值，可进入优先生产或发布队列|
|75–84|A|可用，修复一个主要问题后进入生产|
|60–74|B|仅作实验或局部参考|
|40–59|C|问题明显，不进入优先队列|
|0–39|D|淘汰或重新设计|

# 6\. 原稿明确的附加限制

- 存在硬失败时，最终决策只能是“拒绝”。

- AI 成片商品一致性低于 8/12，不能进入 A 级。

- 可见证据链低于 7/12，不得判为高转化创意。

- 参考视频 AI 复刻友好度低于 6/10，不进入优先复刻队列。

- Owner 人工拒绝时，AI 总分不得覆盖人工结论。

**治理提醒：**“低于 8/12 不能进入 A 级”是否同时禁止进入 S 级，原稿未写明；在 Owner 批准前不得擅自改写为更强规则，遇到 S 级候选必须人工复核。

# 7\. 决策顺序

1. 先核对证据完整性；证据不足时不产出正式成片分。

2. 执行 G0：BLOCK 直接锁定发布结论为拒绝。

3. 继续计算 C 与 R/G，仅用于定位失败和比较方案。

4. 应用子项限制，再映射 S–D 等级。

5. 由 Owner 作最终接受、修复或拒绝决定。
