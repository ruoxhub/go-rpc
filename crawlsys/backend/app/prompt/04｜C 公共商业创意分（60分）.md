# 04｜C 公共商业创意分（60分）

C 适用于参考视频与 AI 生成成片，衡量商业创意是否能让观众看懂商品、相信卖点并产生行动。C 与 R 或 G 二选一路线相加，不能三项并加。

# 1\. 权重总表

|维度|分值|核心问题|
|---|---|---|
|受众与购买需求|6|给谁看、解决什么需求|
|钩子停留能力|10|1 秒内是否产生停留并导向商品|
|商品识别与曝光|6|何时看懂卖什么，商品是否清楚|
|卖点选择|8|是否聚焦 1 个主卖点和最多 2 个辅助卖点|
|可见证据链|12|动作是否真的证明商品结构或好处|
|节奏与信息密度|8|是否快而清楚，不拖沓、不重复|
|记忆点与商品绑定|6|观众记住商品还是只记住背景元素|
|信任、顾虑与行动|4|是否降低顾虑并给出行动理由|
|**合计 C**|**60**|所有分数必须有时间码证据|

# 2\. 受众与购买需求｜6分

- 目标人群、使用场景、购买顾虑清楚。

- 视频动作确实对应这些需求。

- 只写“年轻男性”“喜欢时尚的人”不能获得高分。

# 3\. 钩子停留能力｜10分

- 钩子是否在 1 秒内完成，商品是否立即出现。

- 第一眼主体是否明确，是否具有速度、反差、疑问或情绪。

- 是否自然接入第一个商品卖点。

- 背景钩子有没有抢走商品。

车辆、宠物或灯光很吸睛但没有与商品联动时，最多只能获得中间分。

# 4\. 商品识别与曝光｜6分

- 0–1 秒是否看得出卖什么。

- 商品有效露出时间占比和景别是否合理。

- 手、道具或宠物有没有长期遮挡。

- 结尾是否存在清楚的正面阅读画面。

# 5\. 卖点选择｜8分

- 1 个主卖点，最多 2 个辅助卖点。

- 每个卖点使用不同展示方式。

- 8 秒内不塞入过多信息。

腰头、抽绳、口袋、面料、裤长、颜色和速干同时展示，会造成信息竞争。

# 6\. 可见证据链｜12分

> 商品结构 → 展示动作 → 可见反馈 → 使用结果 → 用户收益
> 
> 

示例：松紧腰头 → 横向拉开 → 位移并恢复 → 腰围存在余量 → 久坐更放松。

- 这是 C 中权重最高的维度。

- 只摸、扫或指，通常只能证明“这里存在”，不能证明弹力、容量或功能。

- 证据链低于 7/12，不得判为高转化创意。

# 7\. 节奏与信息密度｜8分

- 动作起点明确，发力速度快。

- 峰值有短暂停顿，松手和恢复完整。

- 动作衔接短，每个时间段都增加新信息。

- 重复展示相同信息，不算高信息密度。

# 8\. 记忆点与商品绑定｜6分

- 记录主记忆点、辅助记忆点和 3 秒后是否还能复述。

- 检查记忆点是否与商品卖点绑定。

- 若观众只记住金毛、越野车或海浪，却说不出卖什么，绑定不合格。

# 9\. 信任、顾虑与行动｜4分

- 是否真实展示穿着状态。

- 是否解释长度、版型或口袋。

- 是否完整展示拉链打开、放入手机、重新闭合。

- 是否回答尺码、收纳、活动空间等顾虑。

- 是否存在合理 CTA 或购买理由。

# 10\. C 分验收

* [ ] 八个维度合计满分严格等于 60

* [ ] 每个扣分和满分均有时间码证据

* [ ] 钩子导向商品，而非只制造无关刺激

* [ ] 卖点数量受控，主卖点有完整可见证据链

* [ ] 记忆点能回到商品与购买理由
