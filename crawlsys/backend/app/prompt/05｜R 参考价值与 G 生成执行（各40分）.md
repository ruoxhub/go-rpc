# 05｜R 参考价值与 G 生成执行（各40分）

**R 与 G 必须二选一。**参考视频计算 C \+ R；AI 生成成片计算 C \+ G。禁止同一主评审同时把 R 和 G 都加进总分。

# 1\. R｜参考爆款视频价值分（40分）

R 只回答：能不能拆清楚、能不能用 AI 稳定复刻、换成我方商品后会不会串结构。

|维度|分值|评分关注|
|---|---|---|
|时间线与结构可拆解性|8|动作阶段、镜头节点和卖点链路能否清楚还原|
|AI 复刻友好度|10|人物、动作、镜头和物理是否超出稳定生成边界|
|可迁移变量丰富度|8|可替换的场景、钩子、动作、节奏和呈现方式是否足够|
|换成我方商品的安全性|6|迁移后是否容易串色、串结构、错层级或错误证明性能|
|生产成本与稳定性|4|素材、生成、重试和后期成本是否可控|
|差异化潜力|4|是否能在保留有效母版的同时形成自有差异|
|**合计 R**|**40**|C \+ R = 100|

## 1\.1 R 路线限制

- AI 复刻友好度低于 6/10，不进入优先复刻队列。

- 播放量和转化数据单独记录，不直接混入 R 或 C。

- 原稿尚未为 R 的六个维度提供逐项可操作锚点；正式校准前，评分员必须写明时间码和判断理由。

## 1\.2 为什么播放量不能直接决定 R

- 账号体量、自然流与广告流不同。

- 产品价格、发布时间和市场不同。

- 高播放不一定能够复刻。

- 低播放视频也可能拥有优秀的动作母版。

# 2\. G｜AI 生成视频执行分（40分）

|维度|分值|核心检查|
|---|---|---|
|商品一致性|12|颜色、长度、版型和关键结构逐帧一致|
|人物身份与服装层级|5|人物稳定，内外层不粘连|
|动作完整性与力量感|8|抓点、方向、峰值、释放、恢复完整|
|物理、接触与回弹|6|张力、重力、惯性、接触和回落合理|
|镜头与构图连续性|4|姿势、机位、运动和切镜带来新信息|
|技术画质|3|清晰、稳定、无闪烁黑帧和错误文字|
|背景、灯光与声音联动|2|服务动作峰值，不污染或抢走商品|
|**合计 G**|**40**|C \+ G = 100|

## 2\.1 商品一致性｜12分

逐帧检查：颜色、长度、版型、腰头、抽绳、口袋、拉链、图案、开衩、走线、正背面结构和面料观感。这是 G 中权重最高的一项。

- 商品一致性低于 8/12，原稿规定不能进入 A 级。

- 没有商品参考图时，不得断言商品还原准确。

- 如命中商品类 G0，结论直接 BLOCK。

## 2\.2 人物身份与服装层级｜5分

- 人物是否始终是同一人，体型、肤色、纹身和配饰是否稳定。

- 不露脸要求是否执行。

- 内裤与外裤是否独立，上衣与裤子是否发生融合。

## 2\.3 动作完整性与力量感｜8分

> 短促蓄力 → 爆发发力 → 峰值硬停 → 受控释放 → 完全恢复
> 
> 

- 抓点准确、方向正确、幅度清楚、峰值可读。

- 辅助手能引导，且动作真正证明卖点。

- 完全松手，不重复或补拉。

## 2\.4 物理、接触与回弹｜6分

- 面料张力符合受力方向，松手后自然回落。

- 手指不穿透，商品不粘在手上。

- 重力、惯性、烟雾、车辆和反射合理。

## 2\.5 镜头与构图连续性｜4分

- 人物脚位与姿势连续，镜头运动服务卖点。

- 半侧机位能增加纵深证据。

- 一镜到底没有隐性状态重置，切镜带来新信息。

## 2\.6 技术画质｜3分

检查清晰度、曝光、闪烁、多肢与变形、黑帧、编码、错误文字和水印。

## 2\.7 背景、灯光与声音联动｜2分

- 是否与动作峰值同步并增加商品反馈。

- 是否污染商品颜色、造成遮挡或抢夺注意力。

- 背景只能加分，不能挽救商品失败。

# 3\. 专项评分完成标准

* [ ] R 或 G 只选一个，满分严格等于 40

* [ ] 总分只允许 C \+ R 或 C \+ G

* [ ] 所有分项都有时间码或可追溯证据

* [ ] 先应用 G0，再解释总分与等级

* [ ] 真实数据另页记录，不回填主观质量分
